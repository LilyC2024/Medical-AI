# Changelog

All notable changes to LOVISA are recorded here. Dated test outcomes live in
[EVALUATION.md](EVALUATION.md). LOVISA is educational/research software, not a
diagnostic device.

## Unreleased

### Changed
- Review gates resist rubber-stamping: safety, import, CT, endoscopy and final
  report confirmations start unselected; CT and endoscopy candidate decisions start
  empty (a producer's earlier choice is shown only as a caption); every final
  report must be previewed before approval, even with a blank note. The workflow
  enforces the preview rule, not only the UI.
